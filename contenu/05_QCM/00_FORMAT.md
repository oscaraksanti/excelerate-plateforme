# LE QCM — format et raison d'être

## Pourquoi il existe

Le live est à **19 h GMT**. Une grande partie de la promotion le regarde **en replay, le lendemain, sur un téléphone**. Sur un téléphone, on ne peut pas ouvrir Excel, on ne peut pas faire un TP.

**Le QCM est la seule activité possible depuis un téléphone** — et rester engagé entre lundi et mercredi est ce qui prédit le mieux l'achat du mercredi soir.

## Le format

| | |
|---|---|
| **6 questions par module** | pas 10, pas 15 |
| **4 propositions**, une seule juste | |
| **Correction immédiate** | avec une explication d'une ligne, y compris quand c'est juste |
| **Essais illimités** | ce n'est pas un examen |
| **Aucun seuil bloquant** | le TP reste la seule porte du certificat |
| **~2 minutes** | c'est le temps d'une pause |

## Les 6 types imposés

| # | Type | Ce qu'il vérifie |
|:--:|---|---|
| 1 | **Concept** | Il a compris le modèle mental, pas seulement la syntaxe |
| 2 | **Pépite 💎** | Il a appris quelque chose qu'il ignorait — **c'est ce qui prouve la valeur du module** |
| 3 | **Diagnostic** | « Cette formule renvoie 0 / une erreur. Pourquoi ? » |
| 4 | **Choix d'outil** | Formule, Power Query, TCD ou IA ? Et pourquoi. |
| 5 | **Vérification IA** | « L'IA propose ceci. Quel V du protocole l'attrape ? » |
| 6 | **Piège** | Une réponse séduisante et fausse |

## Ce que ça t'apporte, côté admin

Le tableau de bord montre **quelle question est ratée par la majorité**. Tu sais avant 19 h ce que tu dois réexpliquer le soir même.

> Une question ratée par plus de 60 % n'est pas forcément une question difficile — c'est souvent **une leçon mal expliquée**. Regarde-la avant d'accuser les apprenants.

## Règles de rédaction

1. **Les distracteurs sont plausibles.** Trois réponses absurdes ne testent rien.
2. **Le piège reprend l'erreur réelle**, celle que font 80 % des gens — jamais une subtilité inventée.
3. **L'explication est une phrase.** Pas un paragraphe : elle se lit sur un écran de téléphone.
4. **Jamais de « toutes les réponses ci-dessus ».**
5. **Jamais de négation dans l'énoncé** *(« laquelle n'est PAS… »)* : on teste la lecture, pas la compétence.

## Le problème

Aïcha passe trois heures chaque lundi matin à recoller douze fichiers.

Elle ouvre chacun, copie, colle, retire les lignes vides, remet les colonnes dans le bon ordre, refait les totaux. Le mois suivant, elle recommence. À l'identique. Douze fois par an, trois heures à chaque fois — **trente-six heures par an de travail qu'une machine ferait en deux secondes.**

Ce qui l'a empêchée jusqu'ici n'est pas la difficulté. C'est que **personne ne lui a montré que le classeur pouvait se souvenir de ce qu'elle fait.**

## Ce qu'on construit

Une requête. C'est-à-dire : la liste des gestes qu'Aïcha fait chaque lundi, écrite une fois, rejouée d'un clic.

## Le concept

![Une requête n'est pas un résultat : c'est une recette](/lecons/m07/01-les-etapes.svg)

C'est le renversement qu'il faut comprendre avant tout le reste :

> **Power Query ne produit pas un résultat. Il enregistre une suite d'étapes.**

Quand vous supprimez une colonne dans l'éditeur, vous ne supprimez pas une colonne : **vous ajoutez l'étape « supprimer cette colonne »** à une liste. La liste est le livrable. Le tableau qui apparaît dans la feuille n'en est que la dernière conséquence.

D'où les trois propriétés qui changent la vie :

1. **Les étapes se rejouent.** Nouveau fichier, un clic, les huit étapes s'exécutent dans l'ordre.
2. **Les étapes se relisent.** On voit exactement ce qui a été fait, et par qui.
3. **Les étapes se corrigent.** On clique sur l'étape 4, on la modifie, les suivantes se réappliquent.

Un collègue qui nettoie à la main n'a rien de tout cela. Son travail disparaît le jour où il change de poste.

## Le pas à pas

### 1 — Les sources

`Données > Obtenir des données` :

| Source | Quand |
|---|---|
| **À partir d'un fichier > Classeur Excel** | un fichier, connu, stable |
| **À partir d'un fichier > Texte/CSV** | un export de logiciel |
| **À partir d'un fichier > À partir d'un dossier** | 💎 **le cas du module** — tous les fichiers d'un dossier, d'un coup |
| **À partir d'un tableau ou d'une plage** | une table du classeur courant |
| **À partir du Web** | une page, un fichier en ligne |
| **À partir d'une base de données** | SQL Server, Access, et le reste |

**« À partir d'un dossier » est celle qui fait tout le module.** Elle rend une table dont chaque ligne est un fichier — nom, date, extension, et une colonne `Content` qui contient le fichier lui-même. Le mois suivant, on dépose un fichier de plus dans le dossier et il apparaît tout seul.

### 2 — L'éditeur, et le volet des étapes appliquées

`Transformer les données` ouvre l'éditeur. À droite, le volet **Étapes appliquées** : c'est votre recette, dans l'ordre.

Trois gestes à connaître :

- **Cliquer sur une étape** rejoue la requête jusqu'à elle. C'est le seul débogueur dont vous aurez besoin.
- **L'engrenage** à côté d'une étape rouvre la boîte de dialogue qui l'a créée.
- **`fx`** dans la barre de formule affiche le code M de l'étape courante. On y reviendra en leçon 4.

### 3 — 💎 Renommer chaque étape, en français

Clic droit sur une étape > **Renommer**.

Par défaut, votre requête ressemble à ça :

```
Source · Type modifié · Colonnes supprimées · Type modifié1 ·
Lignes filtrées · Personnalisé ajouté · Type modifié2
```

Après :

```
Source — le dossier des agences
Fichiers de ventes uniquement
Mois extrait du nom du fichier
Format normalisé
Colonnes choisies par leur nom
Types posés explicitement
Taux joints sur Mois et Devise
Montant en dollars calculé
```

**Ça ne coûte rien et ça change tout.** La requête devient sa propre documentation — pour le collègue, et pour vous dans six mois.

### 4 — Typer explicitement, toujours

C'est la discipline la moins spectaculaire et la plus rentable du module.

Excel devine les types à partir des 200 premières lignes. Le jour où la ligne 201 contient autre chose, le type change tout seul — et une colonne de montants devient du texte sans prévenir.

> **La règle :** après avoir choisi vos colonnes, posez une étape de typage **explicite**, sur toutes les colonnes, à la main. C'est vingt secondes, et c'est ce qui empêche une requête de « marcher pendant six mois puis plus ».

Et **décochez la détection automatique des types** : `Fichier > Options et paramètres > Options de requête > Détection de type`. Sinon Excel insère une étape de typage juste après la source, avant vos transformations, et elle vous reviendra en pleine figure.

### 5 — Promouvoir les en-têtes

`Accueil > Utiliser la première ligne comme en-tête`.

Attention au cas fréquent : **un fichier avec un titre et une ligne vide avant les vrais en-têtes**. Deux de vos douze agences font exactement ça.

La mauvaise solution : « supprimer les 2 premières lignes ». Elle casse le jour où une agence met trois lignes de titre.
La bonne : **supprimer les lignes jusqu'à celle qui contient « Agence »**. On ne compte pas, on cherche.

### 6 — Les transformations de base

| Geste | Où |
|---|---|
| Supprimer des colonnes | clic droit > Supprimer · ou **Choisir les colonnes** |
| Supprimer des lignes | `Accueil > Supprimer les lignes` — vides, en double, d'erreur |
| Fractionner une colonne | `Transformer > Fractionner la colonne` — par délimiteur, par position |
| Fusionner des colonnes | sélection multiple > clic droit > Fusionner |
| Remplacer des valeurs | clic droit > Remplacer les valeurs |
| Filtrer | l'entonnoir dans l'en-tête |

> 🔴 **« Supprimer des colonnes » et « Choisir les colonnes » ne sont pas la même chose.** Le premier écrit la liste de ce qu'il faut jeter ; une nouvelle colonne arrive, elle passe. Le second écrit la liste de ce qu'il faut garder ; une nouvelle colonne arrive, elle est ignorée. **Choisissez toujours celle qui nomme ce que vous voulez garder** — c'est la même règle que le dépivotage de la leçon suivante.

### 7 — Colonnes depuis les exemples

`Ajouter une colonne > Colonne à partir d'exemples`.

Vous tapez le résultat voulu sur deux ou trois lignes ; Power Query devine la règle et écrit le code M. Pour extraire une année d'un nom de fichier, un code d'agence d'une référence, un domaine d'une adresse email, c'est plus rapide que d'écrire la formule.

**Relisez toujours le M qu'il a produit** — il est affiché en haut de l'écran pendant que vous tapez. Une règle devinée sur trois exemples peut se tromper au quatrième.

### 8 — Charger vers : la décision qui pèse le plus

![Quatre destinations, et trois erreurs de débutant](/lecons/m07/02-charger-vers.svg)

`Accueil > Fermer et charger dans…`

| Destination | Quand |
|---|---|
| **Tableau** | on veut voir les lignes. Jusqu'à quelques centaines de milliers. |
| **Rapport de tableau croisé dynamique** | on ne veut que la synthèse |
| **Ne créer que la connexion** | 💎 la requête existe, rien n'est écrit dans une feuille |
| **+ Ajouter au modèle de données** | 💎💎 des millions de lignes, compressées — **c'est la porte du module 8** |

> 🔴 **L'erreur qui coûte le plus cher :** charger chaque requête intermédiaire dans une feuille. Le classeur passe de 2 à 60 Mo, l'actualisation de deux secondes à deux minutes. **Les requêtes intermédiaires se chargent en connexion seule.** Seul le résultat final va dans une feuille.

### 9 — Le volet Dépendances

`Affichage > Dépendances de la requête` dans l'éditeur.

Une carte de ce qui alimente quoi. Sur une requête simple, c'est joli. Sur un classeur repris de quelqu'un d'autre, **c'est la première chose à ouvrir** : elle vous dit en dix secondes ce que trois heures de lecture ne vous diraient pas.

## Les pépites 💎

**1. Connexion seule + modèle de données.** Un demi-million de lignes sans faire grossir le fichier, parce qu'elles ne sont jamais écrites dans une feuille. C'est ce qui rend le module 8 possible.

**2. Renommer chaque étape en français.** Gratuit, immédiat, et c'est la différence entre une requête qu'on reprend et une requête qu'on refait.

**3. Le volet Dépendances.** La carte du classeur de quelqu'un d'autre.

## Les erreurs fréquentes

- **Laisser la détection automatique des types.** Elle insère une étape avant les vôtres et change de comportement selon les données.
- **« Supprimer les 2 premières lignes ».** Ça marche jusqu'au mois où il y en a trois.
- **Charger tout dans des feuilles.** Le fichier gonfle et l'actualisation devient insupportable.
- **Ne pas typer explicitement.** La requête marche six mois, puis un jour la colonne des montants devient du texte.
- **Nettoyer à la main après le chargement.** À l'actualisation suivante, tout revient. C'est l'erreur de débutant par excellence : **si vous corrigez quelque chose dans la feuille, vous corrigerez la même chose tous les mois.**

## Les raccourcis du soir

| Raccourci | Ce qu'il fait |
|---|---|
| `Alt + A + PN` | Nouvelle requête |
| `Ctrl + Alt + F5` | Actualiser tout |
| `Alt + F12` | Ouvrir l'éditeur Power Query *(selon version)* |
| Dans l'éditeur : `Ctrl + Maj + K` | Ajouter une colonne personnalisée |
| Dans l'éditeur : clic sur une étape | Rejouer jusqu'à cette étape |

## Le mini-défi — 15 minutes

Téléchargez `J07_Agences_mensuel.zip` et décompressez-le dans un dossier.

1. `Données > Obtenir des données > À partir d'un fichier > À partir d'un dossier`.
2. Regardez la table qui apparaît : une ligne par fichier, une colonne `Content`.
3. Filtrez sur les fichiers dont le nom commence par `Ventes_`.
4. Ajoutez une colonne `Mois`, extraite du **nom du fichier**, avec « Colonne à partir d'exemples ».
5. Renommez les cinq étapes, en français.
6. Chargez **en connexion seule**.

Vous n'avez encore consolidé aucune donnée. Vous avez fait le plus important : **la liste des fichiers est devenue vivante.**

## 🎯 Ton fichier à toi

Cherchez, dans votre travail, **la tâche que vous refaites à l'identique chaque semaine ou chaque mois**. Un export à nettoyer, des fichiers à recoller, une colonne à reformater.

Le test : *si je devais l'expliquer à quelqu'un, est-ce que ça tiendrait en une liste d'étapes ?* Si oui, c'est du Power Query.

```
Je refais chaque [semaine / mois] la manipulation
suivante, à la main :
[décris tes gestes dans l'ordre, un par ligne — comme
si tu les dictais à quelqu'un par téléphone]

Le fichier de départ ressemble à ça :
[colle tes en-têtes et deux lignes]

1. Dis-moi lesquels de ces gestes Power Query sait
   faire, et par quelle commande du ruban — pas par
   du code, je veux les menus.
2. Lesquels ne sont PAS faisables dans Power Query,
   et pourquoi.
3. Dans quel ordre les poser, et pourquoi cet ordre.
4. Où se trouve le piège dans MON cas précis : qu'est-ce
   qui cassera le jour où la source changera un peu.
```

Le point 4 est celui qui vaut la peine : **une requête qui marche aujourd'hui n'est pas une requête qui marchera l'année prochaine**, et c'est tout le sujet de la leçon 3.

> **Apportez au direct la liste de vos gestes.** Sur ce module, c'est le plus utile : la moitié des participants découvrent qu'ils font, chacun de leur côté, exactement la même chose.

## Chez vous, demain

Prenez le classeur où quelqu'un colle un export chaque semaine. Ouvrez `Données > Requêtes et connexions`.

Si le volet est vide, vous venez de trouver trois heures par mois à récupérer.

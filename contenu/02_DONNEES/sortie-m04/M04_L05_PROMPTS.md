# Leçon 4.5 — Maquetter avant de construire

## 1. Trois maquettes, jamais une

```
Je dois construire un tableau de bord pour
[qui, et sa fonction].

CE DONT JE DISPOSE
Un tableau t_[nom], une ligne par [quoi], colonnes :
[liste]
[N] lignes, [dimensions].

CE QU'IL OU ELLE VEUT SAVOIR
[la question, en une phrase]

Fais-moi TROIS maquettes différentes, en une page
chacune. Pas trois variantes de la même : trois
partis pris différents.

Pour chacune :
- ce qu'on voit en premier, en haut à gauche
- les quatre indicateurs retenus, et pourquoi ceux-là
- ce qui est volontairement absent
- la décision qu'elle permet de prendre
- CE QU'ELLE SACRIFIE
```

> **« Ce qu'elle sacrifie » est ce qui rend les trois maquettes comparables.** Sans cette ligne, on obtient trois jolis dessins et aucun argument.

## 2. Le message de deux lignes — la vraie pépite 💎

À envoyer **avant** de construire quoi que ce soit.

```
Écris-moi le message de deux lignes que je dois
envoyer à [la personne] pour faire valider la
maquette choisie avant que je construise.

Ton : professionnel, direct, sans jargon. Il doit
pouvoir répondre « oui » en un mot.
```

Le jour où quelqu'un dit « ce n'est pas ça que je voulais », vous avez la trace. C'est un réflexe de consultant, et il vaut plus de temps que toutes les formules du module.

## 3. Maquetter le pire cas

```
Refais la maquette choisie, mais avec :
- le nom de client le plus long de mon fichier
- trois fois plus de lignes dans le tableau
- un montant négatif
- une catégorie dont le libellé fait 40 caractères

Dis-moi ce qui casse.
```

> Les mises en page cassent toujours sur les cas extrêmes — et on le découvre toujours devant le commanditaire.

## 4. Traduire en Excel, honnêtement

```
Voici la maquette validée.
Dis-moi, élément par élément :
1. ce qui se reproduit exactement dans Excel
2. ce qui se reproduit approximativement, et comment
3. ce qui ne se reproduit pas du tout

Pour le point 3, propose l'équivalent Excel le plus
proche — ou dis-moi franchement de l'abandonner.
```

## 5. Le parcours A — sans aucun outil

```
Décris-moi en texte trois dispositions différentes
pour ce tableau de bord. Dessine-les en ASCII si ça
aide. Même structure que ci-dessus, avec le
sacrifice de chacune.
```

**Moins joli, même bénéfice** — le bénéfice n'est pas l'image, c'est la conversation qu'elle provoque.

---

## Ce que l'IA sait, et ce qu'elle ne sait pas

| Elle sait | Elle ne sait pas |
|---|---|
| Proposer des dispositions | Ce que votre direction regarde en premier |
| Choisir une palette lisible | Que le rouge est mal vu dans votre maison |
| Écrire des titres qui affirment | Que « écart » veut dire autre chose chez vous |
| Repérer ce qui n'informe pas | **Si le chiffre est juste** |

**Une maquette valide la forme. Le fond reste au Protocole V4.**
